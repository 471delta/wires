# Wires & Stone

**Wires & Stone | Handcrafted Mineral Wire Jewelry • Alberta, Canada**

A Vite + React site for the Wires & Stone mineral-art atelier.

## Development

```bash
npm install
npm run dev
npm run build
```

Configured for Vite and static deployment to Cloudflare Pages or Vercel.

The gallery intentionally remains under construction. No stock-photo jewelry is used.

The visual system is built around ivory paper, white wood, rose gold, antique rose, champagne gold, walnut, and a restrained cyber-security footer.
